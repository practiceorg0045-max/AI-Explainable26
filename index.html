    03 / PROJECT METHODOLOGY

    How the System Works

    The workflow for student performance prediction and Explainable AI.

    Academic Support

    Use the result as an informational aid when discussing possible support with a teacher.

    Prediction and explanation methodology

    This system is designed to predict student academic performance by analyzing factors such as attendance, previous examination marks, study hours, assignment performance, sleep duration, and class participation. It generates an estimated performance score and provides visual feature-contribution explanations to help users understand how different factors influence the prediction.
